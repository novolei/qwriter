# 素材、灵感匣与截图 · 实现及验证

2026-09-07。本轮在现有 Qwriter 上实现，保留原有文稿、排版与模型配置。浏览器预览与桌面程序的存储彼此独立。

## 使用方式

- **素材与链接**：编辑区顶栏或插入菜单打开；选择本地图片 / 视频、读取剪贴板，或粘贴网页 / 视频地址。预览后确认插入目标。
- **灵感匣**：左栏堆叠卡片入口，窄窗口也可用编辑区顶栏入口。可搜索、固定、编辑、归档、恢复和插入文稿。
- **随手速记**：标题可空，打开后直接输入正文，Ctrl/⌘ + Enter 保存。支持图片、视频附件、剪贴板与来源链接；稍后再写保留草稿，未完成卡片可从灵感匣恢复。
- **截图**：灵感匣 → 截图。桌面版选择屏幕或使用快捷键；浏览器可打开已有图片体验裁剪 / 标注。完成后可复制、导出、保存速记、插入文稿、识字或拼长图。桌面另有置顶参考图及缩放。

| 全局快捷键（桌面程序运行时） | 功能 |
| --- | --- |
| Ctrl/⌘ + Alt + N | 打开独立速记浮窗 |
| Ctrl/⌘ + Shift + Space | 读取已复制的文字 / 图片并打开速记 |
| Ctrl/⌘ + Alt + S | 捕获主显示器后框选；应用内可选择其他显示器 |

在 Chrome 或其他软件中先选中内容并复制，再触发捕捉。无需先展开 Qwriter 主窗口。没有持续监控剪贴板，也不向其他软件注入复制按键。已打开的捕捉窗口优先获得焦点，避免覆盖尚未完成的内容；先收好或收起，再捕捉下一条。快捷键被占用时在截图入口显示失败项。退出程序后快捷键不会继续工作。

## 交互设计

沿用纸白 / 墨绿、羽毛标识、既有中英字体和 Radix 交互组件。灵感匣用可搜索卡片网格展示真实内容；入口的轻量堆叠提示其收纳属性，卡片悬停轻抬，避免持续动画干扰写作。速记正文优先、标题可后补，附件与操作集中在底部。

弹窗高度随视口约束，内部安静滚动；900×640 下保留所有操作，高分辨率下限制阅读宽度。新弹窗之间转场会把焦点交给新输入区域，Escape 可关闭；支持 reduced-motion。已补中英文可访问名称。截图绘图工具通过小型适配层获得键盘按钮语义，绘图本身仍由社区组件提供。

## 复用与版本

| 职责 | 采用的组件 / crate |
| --- | --- |
| 剪贴板、全局快捷键、文件选择与打开链接 | Tauri 官方 clipboard-manager / global-shortcut / dialog / fs / opener |
| Windows / macOS 屏幕像素捕获 | XCap 0.9.8 |
| 框选、标注、放大镜、撤销重做 | react-screenshots **0.5.22** |
| 离线中英文 OCR | Tesseract.js 7 + 本地 chi_sim / eng 语言资源 |
| 网页元数据 | reqwest + scraper / html5ever |
| 桌面卡片与素材索引 | rusqlite / SQLite |
| 浏览器持久化 | idb / IndexedDB |
| 编辑与媒体节点 | 既有 Tiptap 3 + 原生 video 控件 |
| 含素材的 Markdown 导出 | fflate ZIP |

react-screenshots 锁定 0.5.22：实际验证时 0.6.1 的发布包引用了未包含的 CSS 文件，导致 Vite 无法加载。使用完整的稳定发布包并显式导入其样式，没有修改 node_modules，也没有另写绘图引擎。

OCR 的 worker、WASM 和语言数据由 predev/prebuild 复制至 public/ocr，约 75.9 MB。识别时不下载模型、不上传图像。运行文件仅在内容变化时复制，Vite 排除对生成 OCR 目录的监听，避免 Windows 构建时文件锁导致开发服务器退出。

## 数据与模块契约

- `src/features/capture`：卡片、草稿、灵感匣、截图 / OCR / 拼接及独立窗口界面。
- `src/features/editor/media`：媒体协议、预览插入、Tiptap 节点与可移植导出。
- `src/shared/media`：统一资产和剪贴板适配，浏览器数据库。
- `src/app/useCaptureWorkspace.ts`：串联文稿与捕捉模块，插入前核对文稿身份与内容版本。
- `src-tauri/src/services/capture`：资产、SQLite、链接解析、屏幕捕获和桌面生命周期；commands 只做异步 IPC 适配。

桌面资产复制到应用数据目录的 `assets/`；卡片与索引位于同目录的 `captures.sqlite3`。资产使用 SHA-256 内容标识，源文件移动后不影响已保存素材。卡片独立事务和修订号阻止多窗口覆盖。归档可恢复，不做自动硬删除或资产清理。

草稿在 Webview 本地存储中暂存，按卡片保留恢复副本；保存成功后清理相应草稿。截图原始整屏图只在应用缓存 `capture/` 暂存，完成 / 取消时释放；异常退出遗留项在下次启动清理。图片与剪贴板内容不会因捕捉动作发送给 AI。

文稿图片用 `qwriter-asset://<hash>.<ext>` 稳定引用；媒体卡片使用 `qwriter-media` JSON 围栏。普通代码围栏保持原样，非法媒体协议仍作为代码显示。富文本插入不替换用户选中的段落；源码模式追加到文末。编辑器更新绑定文稿身份，防止切换时旧实例写入其他文稿。

有本地媒体的文稿导出为 ZIP，包含 Markdown 与 assets 文件夹；链接卡片转换为普通链接和可用的预览图。本轮没有实现 ZIP 重新导入，也没有把应用内部资产自动同步至 Git 仓库；分享给其他编辑器时应使用该导出包并保留 assets 相对路径。

## 支持范围与边界

| 项目 | 本轮状态 |
| --- | --- |
| 图片 | PNG、JPEG、GIF、WebP；不接受 SVG 执行内容 |
| 视频 | MP4、WebM、MOV；播放受系统 Webview 的编码支持限制 |
| 网页 / 视频页面 | 解析标题、摘要、OG / Twitter 封面；不执行远端页面脚本。可手动补封面。不能保证所有视频网站、登录页或反爬页面都可解析 |
| 视频直链 | 使用原生播放器；视频页面卡片点击打开系统浏览器，不绕过平台限制 |
| 常规截图标注 | 框选、放大镜、矩形、椭圆、箭头、画笔、文字、马赛克、撤销、重做 |
| OCR | 离线中英文，结果可编辑 / 复制 / 随图保存速记；准确率取决于图像 |
| 长图 | 最多 8 张图片手动排序、裁去顶部重叠，再合成；**不是自动滚动截取任意应用** |
| 截图贴图 | 桌面置顶参考窗和缩放；原生交互尚待真机验收 |
| 微信完整功能等同 | **未达到**：自动窗口吸附、自动滚动长截图、编号标注、跨应用自动选择复制等尚未实现 |

单个原生文件导入上限 512 MB；浏览器 / IPC 图片上传与剪贴板上限 32 MB；图片最多 4000 万像素；一张卡片最多 12 个附件；便携导出素材总量上限 256 MB；拼接高度最多 30000 像素。素材永久清理、配额管理与大型媒体流式导出留待后续。

本地 `main`、`capture`、`pin` 使用独立 capabilities。捕捉 / 贴图窗口无模型密钥、Agent、Git 和文稿库 IPC 权限。外链预览验证 DNS 的公开 IP，逐次校验重定向、固定解析地址，并限制响应体与超时。本机当前代理将 `www.rust-lang.org` 解析为 `198.18.6.222`，触发保留地址保护；**本轮真实外链抓取测试未通过此环境限制**，普通链接卡片降级已验证。没有为测试关闭地址校验或修改用户网络配置。

## 验证记录

- `npm run check`：架构、格式、TypeScript、前端测试、Rust fmt / clippy / tests、生成协议一致性。
- `npm run desktop:build`：Windows debug 可执行程序，未制作安装包；路径 `src-tauri/target/debug/qwriter.exe`。
- 浏览器实际完成：图片插入和重载；640×360、2 秒 MP4 解码与插入；网页链接降级；剪贴板文字 / 图片速记；草稿恢复；固定、搜索、归档、恢复；截图框选、键盘选择矩形、撤销重做、复制、OCR 转卡片；两帧长图输出 678×525 后插入文稿；中英浅深主题和 900×640 / 1920×1080。
- 图片导出页面返回成功，但本次 IAB 自动化未收到下载事件，因此未把文件落盘列为已验证。原生文件保存对话框还需桌面实际验收。
- 原有《在文字里，找到自己的节奏》仍为 346 字符，未添加测试内容。测试只写入《多媒体与速记验证》和四张新速记卡片。
- 原生最小化快捷键、真实屏幕捕获、置顶窗口、跨显示器 DPI 与 macOS 屏幕录制权限尚未通过真实桌面交互验收。当前工具仅能操作浏览器，Windows 编译通过不代表这些流程或 macOS 已实测。

验证截图存放于 `docs/audit/2026-09-07-capture-media/`，最终计数见该目录的 `VERIFICATION.md`。
