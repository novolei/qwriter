# 编辑工具与 Git 集成 · 2026-09-07

## 交互设计

保留 Qwriter 的暖纸色与墨绿基调。高频操作放在文稿上方，较少使用的插入功能收进有名称与说明的面板；表格和代码块仅在光标进入时显示专用操作。工具栏使用编辑区域的容器宽度切换布局，侧栏开关不会造成按钮挤出；弹出面板按剩余视口高度限高并允许内部滚动。

快捷字号、衬线切换和行距属于阅读显示偏好，与设置中的文稿字体保持同步，不将字体或字号写入 Markdown。界面字体独立不受影响。选区浮条提供粗斜体和 AI 润色，空段落显示轻量插入入口；所有图标有可访问名称。面板支持 Esc、外部点击关闭和焦点返回。过渡动效以短时透明度和位移为主，尊重 `prefers-reduced-motion`。

段落聚焦突出光标所在块，打字机模式将当前行保持在阅读区域约 42% 的高度；两项为本次窗口的可选模式。标题 1–6、正文、链接、删除线、行内代码、三种列表、引用、代码块、表格和分隔线继续使用 Tiptap / ProseMirror 现有命令及撤销栈。图片使用官方 Image 扩展，补充 Markdown 地址、替代文本和标题的转义；仅插入用户提供的网络地址，没有图片上传或本地素材管理。

选区 AI 捕获当前文段及位置，仅以选段作为模型上下文；结果通过原有 diff 审阅后应用。应用前再次检查文稿 ID 与生成时的完整原稿，文稿变化时拒绝覆盖。替换使用 ProseMirror 的 Slice / replaceRange，保留句子前后内容并进入撤销栈。包含暂不支持语法的 AI 选区结果不会强行转换。当前仍是单轮协作，不是具备任意工具调用能力的多步骤 Agent。

## Git 技术方案

采用 [`git2` 0.21 / libgit2](https://docs.rs/git2/latest/git2/)，启用 vendored libgit2，关闭默认网络特性。仓库状态、diff、索引、提交和历史都交给成熟 Git 实现；Tauri 命令在线程池执行，避免阻塞界面。没有拼接 shell 命令，也不执行 Git hooks。Windows 构建包含 libgit2，不要求用户单独安装 Git CLI。

同时评估了纯 Rust 的 [`gix`](https://github.com/GitoxideLabs/gitoxide)。它适合继续探索性能和纯 Rust 部署；当前优先选择 git2 的工作区、索引和提交 API 完成本地写作流程。没有进行两者的性能基准，因此不声称此实现最快。未来可在 Rust 仓库服务边界内替换或增补实现，UI 不直接依赖底层 crate。

### 当前可用流程

1. 在文稿标题栏打开 Git 工作区，选择一个已有仓库目录；普通目录可通过明确的按钮初始化。位于其他仓库内部时拒绝嵌套初始化。
2. 查看分支、最近 30 条提交、最多 500 项变更。点击文件查看 HEAD 到当前工作文件（包括暂存区）的合并差异。
3. 将当前文稿导出为仓库中的 Markdown 副本，刷新变更后审阅。
4. 主动勾选文件，填写提交说明与署名，在本机创建提交。初始不勾选任何文件；署名优先读取仓库配置，手工输入不修改系统 Git 配置。

### 数据与边界

- SQLite 文稿库与 Git 目录各自独立；目前是明确导出副本的工作流，尚无双向同步、外部文件监听和自动提交。
- 提交前验证 HEAD 未改变；有冲突、正在合并 / 变基、未勾选的已暂存文件或需特殊处理的重命名时阻止提交。路径校验拒绝父级路径和 `.git` 文件。
- 提交会将勾选文件的当前工作内容加入索引。查看差异后若另一个程序继续编辑文件，当前版本不会锁定该外部编辑；应刷新后再提交。暂存成功而创建提交失败时，暂存区可能保留所选内容，不执行自动 reset。
- 文本差异最多约 256 KB；超过 1 MB 的文件不展开完整文本差异，二进制文件不做文本预览。大量改动仅显示前 500 项并提示使用完整 Git 客户端。这里的限制约束展示量，不等于大型仓库状态扫描已经完成性能优化。
- 当前仅本地操作，不包含远程同步、凭据管理、签名提交、分支切换、合并、冲突编辑或 Git LFS。已有 hooks 不会运行；有 hooks 工作流的仓库应使用完整 Git 客户端提交。
- 后续应先实现文件夹文稿与 SQLite 元数据关联、外部变更检测和冲突审阅，再扩展 fetch / pull / push、系统凭据库与分支功能。

## 验证

- 前端 23 项测试通过：新增选区替换与撤销、Markdown 常用节点与图片转义、源码保护、URL 校验、工具栏格式状态、独立排版偏好，以及 Git 勾选文件与提交参数。
- Rust 15 项测试通过：新增真实临时仓库初始化、差异、选中文件提交、未选择暂存文件保护、旧 HEAD 拒绝和已暂存删除提交。测试未对用户的真实仓库初始化或提交。
- Clippy 全部 targets 以 `-D warnings` 通过。
- 浏览器验证中文 / 英文插入面板、鼠标选区浮条、段落聚焦、打字机模式、Git 桌面入口说明；900×640、1100×700、1440×900、1920×1080 CSS 视口无页面横向溢出，插入面板在视口内。
- TypeScript / Vite 与 Windows 独立调试版构建通过，产物为 `src-tauri/target/debug/qwriter.exe`。macOS 编译、签名、公证及原生 Git 目录对话框操作未完成真机验证。
