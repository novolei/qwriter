# 文稿段落导航

2026-09-07：参考用户提供的 Codex 消息导航截图，在正文书写区左侧加入短横条导航。

## 交互

- 非空正文段落、标题、列表项、引用与代码块分别对应横条；表格整体对应一条，图片使用替代文本。空段落和分隔线不占导航位置。
- 标题横条略长，普通段落按摘要长度呈现不同长度；当前阅读段落使用主题强调色。
- 悬停时横条舒展，相邻横条轻微响应；卡片显示段落类型、序号、所属标题与摘要。移动到卡片内可继续阅读，离开后延迟收起。
- 点击平滑滚动至目标段落。定位不改变文稿、不移动已有文字选区，也不写入撤销历史。
- Tab 进入当前导航位置；上下键、Home / End 浏览，Enter 定位，Escape 关闭预览。触屏加大横条点击高度；减少动态效果偏好关闭动画并即时定位。
- 横条保持在纸张左侧留白，大屏跟随居中的纸张；预览卡片限制在编辑区域内。长文导航列表可独立滚动，当前阅读位置进入可见范围。
- 仅有一个有效段落时隐藏；Markdown 源码模式沿用 CodeMirror 行号和搜索，回到正文自动重建导航。

## 实现边界

`features/editor/navigation/blocks.ts` 从 ProseMirror 文档获取真实内容位置，不重复解析 Markdown。`useParagraphNavigation.ts` 处理内容更新、布局缓存、滚动定位与清理；`ParagraphRail.tsx` 负责预览与键盘交互，样式独立存放在 `styles/paragraph-navigation.css`。

正文改变后延迟 120 ms 重建条目，布局变化后重新测量；普通滚动只对缓存位置做二分查找。内容已变、导航尚未刷新时不使用旧位置跳转，避免定位到错误节点。监听与定时器随文稿 / 视图卸载清理。
