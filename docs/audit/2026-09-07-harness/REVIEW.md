# Agent 与紧凑弹窗验收

日期：2026-09-07。Windows 本机，Codex 内置浏览器；原生协议通过本地 HTTP 模拟服务与临时数据库验证。

## 设计判断

原有设置标题、说明、导航之间留白过多，在固定外框中占去了正文空间。沿用纸白 / 灰绿、原有圆角和 64 px 统一导航下划线，将标题由 25 px 调到 21 px，压缩顶部与说明间距。相同 1075×1270 视口、相同模型连接页并排审阅，标题到导航区域由约 218 px 减少到约 158 px，正文多出约 60 px。

## 真实交互与缺陷闭环

| 复现 | 修复 | 复测结果 |
| --- | --- | --- |
| 记忆库点击新增，焦点停留在浮窗容器 | 编辑器挂载聚焦标题；保存 / 取消返回搜索 | 浏览器实际聚焦正确；补初次读取迟到、保存后焦点回归测试 |
| 保存条目后，通用按钮 flex 样式让标题 / 正文 / 来源横向拥挤 | 记忆卡片正文明确按块排布 | 900×640 和英文 1920×1080 无挤压 |
| 已归档复选框继承通用表单列布局，标签跑到下一行 | 记忆库显式采用横向排列 | 复选框与文字对齐；归档后主列表消失，重开后已归档中可找到 |
| 上下文容量受有效范围的 onChange 限制，无法清空重输 | 输入草稿与已保存值分离，失焦校验 | 可清空、输入 32768、按 Tab 保存；正常键盘焦点进入下一项 |
| Agent 附两张图片后，900×640 下按钮文字竖排 | 禁止按钮内部断行，组内允许自然换行 | 中文按钮单行，英文组按宽度换行 |
| 同一场景聚焦输入框把整页向上推 28 px | 工作台允许 flex 收缩、内部滚动 | document.scrollHeight=640，app.top=0，标题未被裁切 |
| 小高度规则隐藏记忆访问说明 | 记忆说明保持可见，不沿用设置副标题隐藏规则 | 900×640 中说明显示完整 |
| 开发服务中断后 lazy App 加载失败出现空白页 | 恢复隐藏运行的 Vite，新增共享启动错误边界 | 浏览器恢复；错误边界英文恢复按钮及不回显异常细节有回归测试 |
| 编码图片超过旧 2 MB 总对话限制，工具跟进被提前终止 | 图片独立 token 配额、请求体上限 16 MB | 图片预处理与大编码图片的两轮 HTTP 回归通过 |
| IndexedDB 冲突路径 abort 产生未处理 rejection | 等待并处理事务终止，再返回业务冲突 | 完整测试无未处理异常 |

## 覆盖的用户流程

- 中文记忆：新增测试条目、保存、搜索、编辑范围、保存、归档、重新打开查看归档。测试条目标注“验收样例”，已归档；没有改动用户文稿。
- 图片：显式添加当前文稿的两张本地图片，出现预览和发送说明；能力未知时，即使填入目标也不能开始。测试附件和目标已清理，没有发送至外部模型。
- 模型设置：能力标记英文显示、展开高级配置、上下文容量重输、键盘 Tab 继续导航。
- 任务：英文任务设置、禁用的默认 thinking 控件、步骤选择入口、浏览器历史空态。真实历史存储与恢复行为由原生数据库测试及前端回归覆盖。
- 900×640 模型 / 字体两页实测外框同为 600×601.59 px；1920×1080 记忆外框为 600×840 px。1440×900 也已检查 Agent 控件。
- 已检查英文深色，最终恢复简体中文、暖白主题，清除临时视口覆盖。
