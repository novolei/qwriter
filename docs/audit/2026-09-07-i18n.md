## 浏览器发现的问题与修复

复现：英文深色界面 → 切换 Markdown 源码 → 打开查找。链接 / 代码围栏使用默认深蓝色，和墨绿背景难以区分。

原因：CodeMirror basicSetup 的默认语法高亮适合浅色，原先只调整了编辑器背景与文字色，没有覆盖语法高亮。

修复：通过 [CodeMirror 官方 HighlightStyle / syntaxHighlighting](https://codemirror.net/docs/ref/#language.HighlightStyle) 接口注册独立 `source-highlight.ts`，使用现有 text / green / muted 主题令牌。不会因为主题切换重建编辑器或清空撤销历史。将已有间接依赖 @codemirror/language 6.12.4、@lezer/highlight 1.2.3 显式声明为直接依赖。

复测：900×640 英文深色和中文浅色中，代码 / 链接随主题呈灰绿高亮，查找控件未被遮挡；已打开的查找面板从英文切到中文后更新，测试文稿保持 114 字符。额外回归验证搜索条件、原始内容和撤销历史不因语言切换丢失。
