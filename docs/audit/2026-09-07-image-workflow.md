# 图片编辑闭环 · 2026-09-07

## 本轮行为

- 每次完成裁剪 / 标注后形成不可变素材引用，修改历史独立于文稿历史。支持连续撤销、重做；恢复原图后仍可重做；撤销后重新编辑会替换后续分支。
- 预览状态明确显示「原始图片」「修改稿 · 未应用」「正在对比原图」与像素尺寸。对比只切换显示，导出和应用继续使用修改稿。
- 存在编辑历史时，关闭触发共用 Modal 确认层。可继续编辑、丢弃并关闭或应用并关闭。Escape 只关闭最上层，焦点回到预览；恢复原图但仍有可重做历史时同样保护。
- 导出成功与取消分别反馈，均不修改文稿。替换原图失败会保留修改稿并显示错误。
- 图像导入与 URL 加载拆入领域 hook；每个源独立会话，关闭取消未完成的远程请求，旧版本 URL 不覆盖新版本。共享标注器忽略卸载后的完成回调。
- 继续复用 react-screenshots 和 shared Modal，无新增依赖、原生命令或权限。标注引导说明先框选，再选择画笔 / 箭头 / 文字，完成后返回预览；中英提示支持换行。

## 边界与后续

- 本轮为前端工作流改进，未重新打包桌面可执行文件，未进行 macOS 真机验证。原生保存对话框取消通过模拟返回值回归覆盖，实际系统对话框仍需桌面复测。
- 编辑历史属于当前浮窗会话；尚不提供重启恢复，也不提供标注图层的跨轮编辑。已有标注按 PNG 结果继续编辑。
