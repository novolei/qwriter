# Qwriter · 工作区与交互组件审阅

本轮按用户提供的截图、当前应用及后续补充实现。重点是释放写作高度、使全局入口归属清楚，并用可复用的组件与协议保证后续功能能够持续完善。

## 观察与改进

| 观察 | 对用户的影响 | 本轮处理 |
| --- | --- | --- |
| 独立的全宽品牌栏与文稿栏叠加 | 顶部约 60 CSS px 被全局信息占用 | 品牌进入左栏，文稿区和 AI 区从顶部开始 |
| 设置、主题、排版属于不同入口 | 收起侧栏后容易找不到设置 | 品牌菜单、左栏底部快捷按钮、编辑区紧凑菜单协同 |
| 原生下拉框与精细设置外观不一致 | 选项面板、焦点和层叠缺少统一感 | 共用 Radix Select、Menu、Dialog；使用应用主题与轻量动效 |
| 小窗口直接隐藏左栏 | 文稿库的重新打开方式不够明确 | 自动收起，显示文字入口与一次性提示；点击打开抽屉 |
| 品牌 Q 与工作区羽毛并存 | 产品标识不统一 | 采用用户选定的羽毛；应用图标、favicon、侧栏及启动页统一 |
| 普通无衬线字标缺少原 Q 的气质 | 品牌与用户偏好的书写风格不一致 | Qwriter 字标采用 Georgia 粗斜体，副标题保留清晰界面字体 |

模型连接和外观设置在常规视口均为 600×840；900×640 视口下外框收缩至约 600×602，切页保持相同尺寸。标题与关闭入口固定，正文独立滚动。

顶部原有的双重工作区介绍已去重。副标题从「每一个想法，都值得留下」开始，六句中英双语短句每 8 秒轮换，采用轻微向上滑入；悬停、键盘聚焦、打开菜单、后台窗口或系统减少动态效果时暂停。品牌菜单提供持久化的轮播开关。

## 验证范围

- 浏览器实测：品牌菜单打开设置；下拉框 Escape 只关闭自身，设置保持打开且焦点回到选择框；切换设置页尺寸不变；窄窗口入口、抽屉 Escape、主题切换。
- 自动回归：27 项前端测试、18 项 Rust 测试；包含 Markdown/AI 审阅与取消、原稿保护、保存冲突、Git 临时仓库边界、字体/语言记忆、弹窗焦点、结构化错误和整数边界。
- 工程检查：严格 TypeScript、Prettier、文件规模与分层、cargo fmt、cargo clippy --all-targets -- -D warnings、生成协议漂移。
- Windows 调试版构建；ICO/ICNS/PNG 由 Tauri CLI 从同一源图标生成。

本地浏览器的开发热更新期间曾因 hook 拆分产生 Fast Refresh 旧状态报错；最终版本重新加载后复核。用户当前文稿的 346 字符和新增的「感谢有你！」均保留，未用真实文稿做编辑测试。

原始基线为 01-before.png，最终截图为 09-branded-workspace.png。同一视口进行了并列检查；基线文稿滚动位置与最终截图不同，因此对比仅用于布局、控件与品牌，不据此宣称正文像素匹配。

macOS 只生成图标并配置 CI，未做本机运行、签名、公证或安装测试。浏览器测试不替代 Windows WebView 原生交互测试；真实云模型、ComfyUI 媒体回插、多步骤 Agent、Git 远程协作仍按 README 所列范围继续开发。
