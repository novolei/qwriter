# 截图浮窗界面修整

目标：延续 Qwriter 的暖纸色、苔绿、细线图标和克制留白，让截图完成后的操作更紧凑，保持中英双语、深浅主题和键盘操作。

## 审阅证据与改动

用户提供的截图 `codex-clipboard-281067ee-931a-465f-8827-fdaea58d71e9.png` 显示：标题图标背景与文字错位；七张等权重大卡片占用两排高度；截图结果、OCR 与操作区缺少清晰层级。

1. 标题栏的宽泛 `span` 样式误伤 BrandIcon，造成额外内边距。改用显式品牌、字标和场景标签类，与侧栏共用官方字标样式。
2. 四个输出操作采用紧凑一排，复制图片作为主操作；继续标注、文字提取、长图拼接、桌面贴图保留直接入口，统一为第二排轻量工具。
3. 预览保持完整图片比例，移除内层滚动；OCR 使用独立卡片，复制入口放在标题旁，支持编辑、复制反馈与识别取消。窄屏输出操作自动两列排列。
4. 添加克制的悬停与 OCR 入场过渡，遵循 reduced-motion。分组具有中英可访问名称，空 OCR 文本不允许复制。
5. 实机发现 Escape 未统一收起浮窗，新增独立 hook，避让标注、嵌套对话框和输入法组合；保留原有草稿暂存关闭路径。
6. 实机发现导出截图建议文件名没有扩展名。按素材实际格式补齐浏览器下载与原生建议文件名，并提供原生格式筛选。保持原文件名主体，不修改素材与文稿内容。

## 验证

- Windows 原生：全局快捷键从资源管理器调起截图，裁剪完成进入结果浮窗；品牌图标与字标居中；七个操作入口齐全；保存对话框位于置顶浮窗前方。
- 浏览器：打开图片、裁剪、完成、OCR、编辑区展示及复制文字反馈；900×640、420×700、常规桌面视口；中文暖白和英文深色模式。英文截图界面未残留中文 UI 文案。
- 新增回归测试：Escape 监听生命周期、输入法和嵌套层级；原生及浏览器文件名扩展名补齐。
- 最终构建实测 Escape 可收起空白速记浮窗。`npm run check` 全部通过：81 项前端测试、32 项 Rust 测试（3 项原有测试忽略），架构、i18n、格式、Clippy 与协议漂移检查通过；`npm run desktop:build` 成功。
