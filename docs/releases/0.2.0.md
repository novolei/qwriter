## Qwriter 0.2.0 · Preview

首个公开测试版。欢迎通过仓库 Issues 反馈问题；报告时请附上系统、版本与复现步骤，并移除文稿隐私及 API Key。

### 下载 / Downloads

- **Windows x64**：下载 `Qwriter_0.2.0_x64-setup.exe` 安装器。内置 WebView2 引导程序，缺少运行时时需要联网下载。
- **macOS Apple Silicon / Intel**：下载 `Qwriter_0.2.0_universal.dmg`，将 Qwriter 拖入 Applications。
- `SHA256SUMS.txt` 用于核验安装包完整性。GitHub 自动提供的 Source code 压缩包是源码，不是安装器。

### 本版内容

- 简约写作界面、Markdown 工具栏、可配置中英文字体及双语界面。
- 供应商与模型池管理、流式 AI 写作、草稿审阅及本地文稿历史。
- 全局截图、窗口识别、标注、取色、OCR 与灵感速记。
- Windows 启动不再伴随控制台；改善截图唤起性能。
- 截图导出自动补齐或纠正图片扩展名，避免生成无扩展名文件。

### 测试状态与已知限制 / Testing and limitations

- Windows 与 macOS runner 均已通过完整工程检查，并生成 Release 优化构建。
- Windows 原生截图导出流程已实测；下载后的安装器尚未完成全新系统安装验收。
- macOS 为 **ad-hoc 临时签名，尚无 Developer ID 签名及 Apple 公证**，可能受到 Gatekeeper 限制。Mac 真机上的安装、截图权限和全局快捷键仍待验证。
- macOS builds are ad-hoc signed and not notarized. Installation, screen recording permissions and global shortcuts still require real-device testing.
- 模型服务需使用用户自己的配置；安装包不含开发者的 API Key、文稿或本地数据库。

This is a preview for testing, not a fully validated stable release.
